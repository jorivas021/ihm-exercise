Formulaire Initial vs Interface Refondue

AVANT : Formulaire Initial
  • ✕ Champs muets (1 à 5) : Aucun libellé ni exemple pour identifier l'information attendue.
  • ✕ Erreur globale en bas : "Certains champs sont invalides" sans localiser la faute.
  • ✕ Ambiguïté totale : Impossible de savoir quels champs sont obligatoires avant la soumission.
  • ✕ Bouton "Envoyer" statique : Aucune indication sur la progression ou la validité avant le clic.
APRÈS : Solution Ergonomique
  • ✓ Guidage explicite : Libellés clairs, sélecteur dynamique Cycle → Filière et indicatifs téléphoniques internationaux.
  • ✓ Erreurs ciblées en temps réel : Message précis juste sous le champ concerné dès la saisie.
  • ✓ Incitation visuelle : Astérisque rouge (*) sur les 6 champs requis.
  • ✓ Rétroaction complète : Barre de progression (0/6), sauvegarde auto, mode sombre et bouton adaptatif.
